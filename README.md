# Final project

This repository contains the final project for the IBM Developing AI Applications with Python and Flask course.

The project builds an emotion detection application using the Watson NLP library and deploys it as a web application with Flask.

## Features
- Emotion detection from text input.
- Returns anger, disgust, fear, joy, sadness, and the dominant emotion.
- Handles blank input with an error message.
- Web deployment using Flask.

## Project Structure
- `emotion_detection.py`
- `server.py`
- `test_emotion_detection.py`
- `EmotionDetection/`
- `templates/`
- `static/`

## Usage
Run the Flask application and open it in the browser to analyze text emotion.
